# Project 15: File Sharing Platform (SKYVAULT)

Distributed cloud storage and granular file-sharing platform built with React, Vite, TailwindCSS, and Zustand.

## Features
- **Soft Blue-Gray Theme**: High-contrast, clean corporate file manager interface (`#f1f5f9`, `#334155`, `#0284c7`).
- **Drag-and-Drop Dropzone**: Chunked simulated cryptographic upload engine with live progress animations.
- **Hierarchical Storage Directories**: All Files, Engineering Blueprints, Legal Compliance, 4K Media Assets.
- **Granular Sharing Permissions**: View/Edit roles, ephemeral TTL expiration tokens (24h, 7d, 30d, permanent), and password locks.
- **Immutable Version Ledger**: Full file version history (v1.0, v2.3, v2.4) with rollback simulation.
- **In-Browser Document & Media Preview**: Render previews for PDFs, YAML/code configs, images, and text documents.
- **Storage & Egress Analytics**: Storage quota breakdown by file type and download/share telemetry.

## Getting Started
```bash
npm install
npm run dev
```
